# NerdFM M3 implementation report

## Scope implemented

- Added a People & Dressing Room screen with deterministic player personality labels, morale, leadership figures, cohesion, board objective selection, media responses, and playing-time promise controls.
- Added an eight-week playing-time promise lifecycle. Repeated missed-minute expectations lower morale and can produce a player/agent demand news item; injured/suspended players are not penalised for a missed appearance.
- Added bounded team cohesion updates based on squad morale, leadership, and player participation.
- Added manager reputation and objective-sensitive board confidence updates after the human fixture.
- Bumped the save schema to version 2 and added an in-memory version-1 migration that initializes the newly introduced M3 state while preserving the existing career data. Existing Java serialization UIDs were not changed.
- All new simulation rules live in `PlayerRelations.kt`, which has no Android imports. UI interactions are in Compose.

## Known risks

- Board objective progression is intentionally a lightweight first model and needs a season-level balance pass.
- Personality labels are derived deterministically from existing player attributes rather than random narrative traits, so they remain stable but have limited variety.
- The player/agent demand system currently reports unmet promises; transfer-contract negotiation demands are not included in this milestone slice.
- CI green remains the acceptance gate. Do not begin M4 until M3 CI is confirmed green.
